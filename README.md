Папка update/ - всё для обновления роутера Almond3S с GitHub
=============================================================

Что внутри
----------
  update.sh                      - скрипт обновления (качает plain-файлы)
  etc/almond3s/scripts/weather_fetch.sh  - погодный скрипт (с прогнозом)
  usr/libexec/almond3s/ui.uc     - интерфейс ЖК-экрана (строка прогноза,
                                   тройка «Ощущается/Влажность/Ветер» и т.д.)

Как создать репозиторий
-----------------------
  1. Создать github.com/zipfo/almond3s-gismeteo (public - иначе raw-ссылки
     не отдадут файлы без токена), ветка main (подойдёт и master).
  2. Загрузить СОДЕРЖИМОЕ этой папки с сохранением структуры каталогов,
     то есть в репозитории должны получиться пути:
        update/update.sh
        update/etc/almond3s/scripts/weather_fetch.sh
        update/usr/libexec/almond3s/ui.uc
     (подойдёт и вариант без папки update/ - скрипт ищет файлы и в корне)

Как обновиться на роутере
-------------------------
  Одной строкой (ssh на роутер):
    curl -fsSL https://raw.githubusercontent.com/zipfo/almond3s-gismeteo/main/update/update.sh | sh

  Если файлы лежат в корне репозитория (без папки update/):
    curl -fsSL https://raw.githubusercontent.com/zipfo/almond3s-gismeteo/main/update.sh | sh

Бэкап и восстановление
----------------------
  - Первый запуск перед записью кладёт оригинальные файлы в
    /root/almond3s-bak/ (этот снимок сохраняется навсегда).
  - Каждый следующий запуск видит бэкап и спрашивает:
        [r] - восстановить файлы из бэкапа (откат к оригиналу)
        [u] - обновить файлы из GitHub
        пусто - выход
  - Без терминала (например, из cron) скрипт не гадает и завершается
    с ошибкой.
